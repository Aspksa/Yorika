# Безопасная проверка загрузки Yorika

Если антивирус (например Kaspersky) показывает `HEUR:Trojan.PowerShell.Agent.c`
при скачивании ZIP всего проекта, **не отключайте защиту**, не добавляйте
исключение и не пытайтесь принудительно сохранить заблокированный файл.

Это эвристический детект: он **не доказывает** наличие трояна и не
доказывает безопасность архива. Нужно проверить конкретные файлы и результат
анализа антивирусного вендора.

## Что уже сделано для снижения рисков

- В запуске `ЦЕНТР_YORIKA/ЦЕНТР_YORIKA.bat` убран аргумент
  `-ExecutionPolicy Bypass`: политика PowerShell на компьютере соблюдается.
- Нет автоматического отключения Defender/Kaspersky, создания исключений,
  запуска PowerShell со скрытым окном или запуска скачанного ZIP без проверки.
- Ключи через меню центра сохраняются локально через Windows DPAPI; их не
  нужно передавать в чат, GitHub Issues и антивирусные отчёты.

## Что проверить

1. В Kaspersky откройте событие детекта и сохраните **только** имя
   угрозы, точный файл внутри архива (если указан), версию баз и дату.
   Не публикуйте токены, ключи и URL с параметром `token=`.
2. Скачайте или проверьте исходники **только в разрешённой и изолированной
   среде**. Если Kaspersky блокирует проект, не обходите блокировку.
3. Проверьте исходники PowerShell, особенно скачивание и запуск программ,
   сохранение секретов и возможные сетевые команды. Проверьте зависимости.
4. Если детект признан ложным после проверки, направьте архив или образец
   **через официальный канал Kaspersky для false positive** с идентификатором
   детекта и контрольной суммой. Дождитесь анализа производителя.

## Ограничения

Мы не можем гарантировать, что эвристика исчезнет после изменения запуска.
Архив содержит и другие PowerShell-скрипты, поэтому необходима проверка
конкретного сигнатурного срабатывания. Отсутствие детекта не является
подтверждением безопасности кода.

Если локальная политика запрещает выполнение неподписанных PS1, используйте
доверенную подписанную поставку или согласованную настройку администратора.
Не применяйте обход политики исполнения.
