# Экспорт данных браузера Yorika

На странице `Настройки → Данные браузера` добавлена кнопка **«Скачать копию JSON»**. Она сохраняет локальный файл `yorika-browser-backup-YYYY-MM-DD.json` с форматом `yorika-browser-data-v1`, датой выгрузки, origin и шестью разделами IndexedDB: settings, projects, memories, conversations, messages, tasks.

Экспорт использует текущий адрес `http://localhost:PORT`. IndexedDB привязан к origin, включая порт: данные старых портов автоматически не читаются, и копия не объединяет разные origin. Функция не отправляет данные в облако, не очищает IndexedDB и не включает локальные серверные секреты из других хранилищ.

**Осторожно:** файл может содержать персональные сообщения, задачи и воспоминания, не шифруется и должен храниться в защищённом месте. Разделы читаются последовательно и не образуют единую атомарную транзакцию, поэтому при параллельном редактировании возможна несогласованная копия. При ошибке выгрузки скачивание не запускается.

Импорт такого файла в браузер, подключение SQLite к серверу и перенос данных со старых origin ещё не реализованы. Это лишь первый пользовательский шаг по задаче DATA-002; её статус не меняется.
