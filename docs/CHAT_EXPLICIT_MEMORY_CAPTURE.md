# Явная запись фактов из чата

Сообщение пользователя, начинающееся строго с `Запомни:` или `Remember:`, теперь сохраняет остаток текста в пространстве SQLite `memories` при успешной записи истории чата. Источник: `explicit-chat-request`; `source_id` образуется из SHA-256 исходного сообщения и времени. Это защищает от повторного добавления одного и того же сообщения при синхронизации вкладок.

Обычные реплики пользователя, ответы бота и сообщения без разделителя не превращаются в воспоминания. Пустые факты и записи длиннее 3000 символов пропускаются. При конфликте ревизий ни история, ни новые факты не записываются. Очистка истории чата не удаляет отдельно сохранённые факты; удаляйте их через соответствующие средства управления памятью.

**Ограничения:** это явный захват текстовых команд, не автоматическое понимание или семантическое извлечение фактов. Факты не проверяются на истинность; настоящая модель и полный Windows end-to-end тест ещё не готовы.
