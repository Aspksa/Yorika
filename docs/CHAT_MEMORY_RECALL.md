# Получение воспоминаний во время диалога

Новый API `POST /api/memory/recall` принимает JSON `{"query":"..."}` только с локального origin Yorika и передаёт текст в `scripts/recall-memory.py`. Обработчик выполняет **чтение** SQLite `memories`: FTS5 ранжирует совпадения, а при отсутствии FTS5 используется буквальный поиск.

Чат показывает найденные записи, их источники и идентификаторы, если они были сохранены через `Store.remember(...)`. Результат явно обозначен как **поиск по памяти, а не генерация языковой модели**. При отсутствии результатов чат сообщает об этом без выдуманного ответа.

Ограничения: язык модели и автоматическое извлечение фактов ещё не подключены, воспоминания должны быть явно сохранены. Экран `memory.html` по-прежнему обращается к браузерной IndexedDB, а не к этому SQLite API. Автоматическое разрешение противоречий не реализовано. Windows и полный HTTP smoke-test ещё не подтверждены.
