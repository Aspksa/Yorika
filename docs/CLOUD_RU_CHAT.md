# Cloud.ru Foundation Models — основной движок ответов Yorika

Yorika использует сервис Cloud.ru **Foundation Models**, а не локальную Ollama. Официальный endpoint: `https://foundation-models.api.cloud.ru/v1/chat/completions`, совместимый со схемой OpenAI. Для данного сервиса используется `Authorization: Bearer <API-ключ>`; IAM keyId/secret и сервис ML Inference требуют другого подключения.

## Настройка (без передачи ключа в чат)

1. В Cloud.ru выберите AI Factory → Foundation Models и убедитесь, что API-ключ сервисного аккаунта разрешён для **Foundation Models**.
2. На Windows настройте переменную окружения `YORIKA_CLOUD_RU_API_KEY` в контексте учётной записи, которая запускает `Yorika.bat`. Не помещайте ключ в Git, файлы сайта, браузерное хранилище или логи. Убедитесь, что процесс Yorika видит обновлённое окружение после перезапуска.
3. Необязательно задайте `YORIKA_CLOUD_RU_MODEL` — точный ID модели из личного кабинета Cloud.ru. По умолчанию используется документированный `ai-sage/GigaChat3-10B-A1.8B`.
4. Перезапустите Yorika и отправьте сообщение в чат. `/api/chat/respond` теперь вызывает `scripts/cloud-ru-model.py`. При отсутствии ключа/сети чат перейдёт к локальному поиску сохранённых воспоминаний вместо генерации.

Не храните секрет в **постоянной пользовательской переменной окружения**, если вы не готовы к тому, что он может быть прочитан другими процессами этого пользователя. Это временная серверная интеграция, **не завершённый менеджер ключей**: Windows DPAPI-хранилище, пользовательский экран ввода и удаления ключа и успешная Windows-приёмка остаются отдельными задачами.

**Конфиденциальность и расходы:** при отправке запроса Cloud.ru получает сообщение пользователя и до трёх текстовых воспоминаний (ограниченный контекст). Это внешний облачный сервис, использование которого может тарифицироваться. Отдельный opt-in для автоматической выгрузки больших наборов памяти/обучения не включён, фоновая тренировка не запускается. Не используйте данный провайдер, если данные не должны покидать компьютер. Лимит ответа задан максимумом 450 токенов, но это не жёсткое денежное ограничение.

Документация: https://cloud.ru/docs/foundation-models/ug/topics/quickstart и https://cloud.ru/docs/foundation-models/ug/topics/api-ref__specs

Данный PR не объявляет CLOUD-002/003/004/005 завершёнными — без DPAPI, UI и end-to-end Windows-тестирования это неверно.
