# Безопасная проверка Cloud.ru

**Проверить подключение** теперь выполняет только минимальный тестовый запрос к Foundation Models с `include_memory=False`. Он не открывает SQLite и не прикрепляет личные воспоминания. Ответ остаётся проверкой реального API-ключа и модели, поэтому запрос может тарифицироваться.

Обычная отправка сообщения в чат по-прежнему использует до трёх найденных воспоминаний для контекста, как и прежде. Это отдельный сценарий с передачей данных в Cloud.ru: пользователи должны учитывать конфиденциальность и тарифы.

Регрессионные тесты запрещают обращение к Store во время проверки соединения и проверяют отсутствие памяти в JSON-запросе. Статус/диагностика без внешнего запроса также не должны возвращать значение ключа.

Проверку с реальным ключом и end-to-end тест на Windows необходимо подтвердить отдельно; CI, сообщавший ошибку без доступных журналов шагов, не считается пройденным.
