# Cloud.ru в настройках Yorika

Новая панель **Настройки → Cloud.ru — ИИ** позволяет сохранить API-ключ Foundation Models, выбрать точный ID модели, проверить соединение и удалить локальный ключ. Проверка по кнопке отправляет короткий запрос в Cloud.ru и может тарифицироваться.

## Хранение и защита

Сервер принимает сохранение только методом POST с проверками Host и Origin текущего `127.0.0.1:PORT`. Python записывает ключ и модель в файл `%LOCALAPPDATA%\\Yorika\\secrets\\cloud-ru.dpapi`, предварительно шифруя JSON Windows DPAPI в режиме **CurrentUser** и `CRYPTPROTECT_UI_FORBIDDEN`. Сохранение идёт через временный файл и `os.replace`. В браузер возвращается только `configured`, ID модели и способ хранения: API-ключ никогда не возвращается обратно.

После перезапуска `scripts/cloud-ru-model.py` читает сохранённые параметры из DPAPI. Прежняя переменная окружения остаётся резервным способом настройки только при отсутствии файла. При удалении файла облачный ключ **не отзывается** у провайдера — при компрометации отзовите его также в Cloud.ru.

## Ограничения и проверка

DPAPI-защита привязана к пользователю Windows; файл не переносим как обычный JSON. Не сохраняйте ключ в чате или репозитории. Код не предназначен для macOS/Linux; они не сохраняют ключ без DPAPI. Наследуемые ACL каталога `%LOCALAPPDATA%` не проверяются отдельным тестом и должны быть проверены на целевой машине. DPAPI не защищает от вредоносного кода, уже запущенного под тем же пользователем.

Для тестов: `python -m unittest tests.test_cloud_ru_vault tests.test_cloud_ru_model -v`; далее на Windows проверяйте сохранение, перезапуск, проверку API, смену модели, удаление и отсутствие ключа в HTTP-ответах и логах.

**Доступность:** без фактического API-ключа и Windows среды реальную облачную авторизацию и приёмку не подтвердить. До этого задачи CLOUD-002–005 нельзя считать полностью завершёнными.
