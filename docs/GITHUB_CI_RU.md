# Автоматические проверки Yorika — инструкция

## Где что смотреть

- **Actions → Yorika | Автопроверка изменений** — автоматически при Pull Request и push в `main`. Проверяет Python, JavaScript, имена файлов с возможными ключами и Python/SQLite-тесты. Внизу каждого запуска — русский раздел **Summary**, приложен `ОТЧЁТ_YORIKA.md`.
- **Actions → Yorika trusted Windows self-hosted acceptance** — **только вручную из `main`** на своём проверенном Windows runner `yorika-ci`. Диагностирует PowerShell 7, Node.js и отдельный Python 3.12, затем запускает Windows-тесты. При пропуске проверки отчёт не должен показывать зелёный успех.
- **Actions → Yorika | Подготовка архива (без публикации)** — **вручную из `main`**; только после пройденных Python/SQLite-тестов собирает архив из отслеживаемых Git исходников и выдаёт SHA-256. Не публикует релиз и не подтверждает безопасность Касперского.

Ранее существовавшие `chat-memory-tests.yml` и `windows-validation.yml` продолжают работать. Поскольку минуты GitHub-hosted Actions исчерпаны, автоматические задания могут **не стартовать** до восстановления квоты; красный результат на этапе выделения runner не является результатом тестов. GitHub-состояние не следует приписывать выполнению локальных проверок.

## Значения статусов

- ✅ **УСПЕШНО** — выполненная проверка завершилась без ошибок.
- ❌ **ОШИБКА / СБОЙ** — тест провалился или не удалось получить результат.
- ⚠️ **ПРОПУЩЕНО** — проверка не запускалась и не считается успешно выполненной.

### Секреты и безопасность

CI не должен иметь личные ключи Cloud.ru и доступ к рабочему профилю Windows. Автоматическая проверка `ci-secrets-check.py` обнаруживает **только опасные имена файлов Git** (например, `.env`, `id_rsa`, `.pfx`), она **не** сканирует содержимое и не заменяет полноценный аудит секретов. При подозрении на утечку отзовите ключ и проверяйте историю Git.

Self-hosted Windows работает только с проверенной веткой `main` и не запускает PR-код. GitHub Actions сами по себе не устраняют предупреждение Kaspersky. Не отключайте антивирус и не ослабляйте PowerShell Execution Policy ради CI.

## Ограничения и будущие расширения

- Графический интерфейс Yorika и настоящий Cloud.ru требуют отдельной изолированной приёмки.
- Архив с SHA-256 подтверждает целостность архива **после формирования**, но не его безопасность или подлинность издателя.
- Для выпуска релиза нужны подтверждённые Windows-тесты, проверка антивирусного обнаружения и решение о публикации.
