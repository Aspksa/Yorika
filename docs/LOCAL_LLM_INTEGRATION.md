# Локальная модель Yorika — подключение

В этом PR добавлена **опциональная интеграция с уже установленным локальным Ollama**, а **не собственная обученная нейросеть Yorika**. В репозитории отсутствуют веса и тренировочный pipeline собственной LLM. Для запуска требуется отдельно установить Ollama и загрузить поддерживаемую модель (например, llama3.2). Пользователь сам отвечает за её лицензию, ресурсы и качество ответов.

1. Запустите Ollama на локальном компьютере (127.0.0.1:11434).
2. В окружении процесса Yorika установите `YORIKA_LOCAL_MODEL` равным имени установленной модели.
3. Перезапустите Yorika. Чат сначала делает `POST /api/chat/respond`, а при недоступности модели возвращается к прямому поиску SQLite-памяти.

Сервер Yorika принимает запрос только на своём loopback origin, с проверкой Host, Origin и максимальной длины. `scripts/local-model.py` отправляет текст только на `http://127.0.0.1:11434/api/chat`; произвольный URL и cloud endpoints не принимаются. До трёх воспоминаний из пространства `memories` вставляются в системный контекст с источниками. Данные не уходят за пределы компьютера через этот модуль, если сам inference-сервер не настроен пользователем на внешнюю пересылку.

Ограничения: это однократный диалоговый вызов без потоковой генерации. Сохранённые воспоминания — **недоверенные сведения**, а не команды. Текстовые инструкции не гарантируют защиты от prompt injection. Верность выводов модели не проверяется; противоречивые факты требуют ручной проверки. Зависит от Python и доступного Ollama. Полноценный Windows запуск с моделью и нагрузочный тест в этом PR не выполнены.
