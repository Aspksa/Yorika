# Проверка расхождений в памяти

Метод `Store.find_memory_conflicts(subject, limit=100)` предназначен для явных структурированных утверждений в пространстве имён `memories`.

Пример записи:

```json
{"subject":"favorite_color","claim":"синий","source":"user","source_id":"chat-1"}
```

Если для одинакового `subject` найдены **различающиеся текстовые `claim`**, метод возвращает их для ручной проверки вместе с источниками, идентификаторами и ID записей. Совпадения сравниваются без учёта регистра и пробелов по краям. Результат пустой, если обнаружена одна версия утверждения. Сканирование ограничено выбранным `subject`, предельное число совпадений — `limit` (1–1000), при превышении выводится ошибка.

Это **детектор расхождений, не доказательство логического противоречия**: разные утверждения могут быть одновременно верны в разное время или при разных обстоятельствах. Метод не меняет данные, не определяет истину, не объединяет утверждения и не извлекает факты из свободного текста. Без `subject` и `claim` записи не участвуют. Полноценное семантическое выявление конфликтов и разрешение их в интерфейсе остаются открытыми.
