# Проверка противоречий с сохранением контроля пользователя

`Store.review_memory_claims(subject, limit=100)` классифицирует пары структурированных утверждений в памяти. При одинаковом `subject` он различает дословно совпадающие утверждения, явное начальное отрицание (`не` / `not`) и прочие расхождения. Возвращает `no_disagreement` либо `review_required` со списком пар и источников.

Класс `explicit_negation` — эвристика для ручной проверки, **не доказательство логического противоречия**; контекст, время, субъект высказывания и сложная грамматика пока не анализируются. `different_claims` также не означает, что одно из утверждений ложно. Данные не меняются, и решение всегда `manual_review`.

Собственная языковая модель отсутствует в текущем репозитории: обучение, модельные веса, инференс и Windows-приёмка не входят в этот PR. Нельзя считать этап 4 полностью закрытым.
