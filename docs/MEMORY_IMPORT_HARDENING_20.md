# Укрепление импорта памяти: 20 рубежей проверки

Пакет к `Store.import_records(bundle, dry_run=True, on_conflict="reject")` добавляет строгую приёмку экспорта SQLite до любых записей. Обратная совместимость с `Store.export_records()` сохранена.

1. Тип пакета: словарь.
2. Точный набор ключей пакета без скрытых добавочных полей.
3. Поддерживаемая версия `yorika-records-v1`.
4. Строковое непустое имя пространства.
5. Максимум 256 символов у имени пространства.
6. Запрет управляющих символов в имени пространства.
7. Только массив записей.
8. Максимум 100 000 записей.
9. Строго логическое `dry_run`.
10. Только политики конфликта `reject` и `skip`.
11. Каждая запись — словарь с точными ключами `record_id/value/updated_at`.
12. Непустой строковый ID длиной не больше 512 символов.
13. Запрет управляющих символов в ID.
14. Отклонение повторяющихся ID в одном пакете.
15. Значение записи обязано быть объектом JSON.
16. Временная метка — ISO8601-совместимая строка длиной до 64 символов.
17. Часовой пояс обязателен; метки без часового пояса отклоняются.
18. Запрет несерилизуемых, бесконечных, NaN и некорректно закодированных Unicode-значений.
19. Максимум 1 МиБ JSON на запись и 32 МиБ совокупно по тексту значений.
20. Импорт остаётся транзакционным, без перезаписи: по умолчанию предварительный просмотр; конфликт либо отклоняется, либо пропускается.

Возвращаемый отчёт включает `namespace`, `dry_run`, `requested`, `conflicts`, `eligible`, `applied`, `bytes`.

**Границы гарантии:** 32 МиБ — лимит сериализованных `value`, а не полного размера Python-объектов/файла; большие списки метаданных также могут потреблять память. Прямой вызов требует доверенного локального процесса. Сохранение имени `namespace` не означает согласия на экспорт секретов. Это не импорт браузерного IndexedDB и не UI редактирования. `MEMORY-005` и `DATA-002` ещё не завершены.

Реальные тесты на Windows требуют работающего CI и отдельной приёмки.
