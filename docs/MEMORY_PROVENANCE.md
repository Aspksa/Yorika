# Воспоминания с происхождением

`Store.remember(record_id, text, source, source_id="")` явно сохраняет текстовое воспоминание в `memories` с полями `text`, `source`, `source_id`, `created_at`. Поля обязательного источника и времени полезны для аудита и последующей проверки противоречий. Для повторных ID используется обычное поведение `put` (upsert), поэтому это не механизм неизменяемой истории источников.

Метод не извлекает факты автоматически и не определяет правдивость воспоминания. Используйте конкретный источник, например `user-confirmed`, и идентификатор исходного сообщения, когда он известен. Для конфликтов будущей реализации понадобится отдельная ревизия/история.

FTS5 может извлекать такой текст через `Store.search_records_fts("memories", query)`. Интеграция в генерацию ответа и полноценное семантическое ранжирование ещё не реализованы.
