# Yorika — продолжение единого мозга

`backend.neural_resume.resume_training(examples, source, output, additional_steps=...)` продолжает обучение единственной архитектуры с весов доверенного локального checkpoint и создаёт **новый** файл, не меняя активный `active-brain.json`. Структура словаря, seed и размеры сети строго совпадают с исходной моделью.

**Ограничение:** состояние AdamW не сохраняется. Новый оптимизатор создаётся заново, поэтому это продолжение **весов**, а не побитовое восстановление обучения с того же шага. Для настоящего recovery необходимы optimizer state, RNG state и точное положение в потоке данных. Реальный smoke выполняет два шага, продолжает ещё на два, проверяет обе версии и генерацию текста.

Примеры должны быть разрешены для обучения и идентичны по словарю исходному набору; никакого Ollama, автоматического переключения мозга и подтверждённой RTX-приёмки.
