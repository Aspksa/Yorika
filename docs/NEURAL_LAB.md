# Yorika Neural Lab — сохраняемые эксперименты

`backend/neural_lab.py:run_lab` создаёт **новый** каталог исследования, разово обучает 2–5 вариантов собственной модели с разными шириной, числом голов и контекстом, сохраняет их checkpoints и отдельный `report.json`.

- Данные делятся до обучения: отложенная выборка не передаётся trainer.
- После обучения каждая модель тестируется на тех же отложенных примерах. Проверяются SHA-256 набора и checkpoint.
- Для каждой версии сохраняются архитектурная конфигурация, loss, время обучения, время оценки и размер файла.
- При ошибке неполный каталог удаляется. Каталог с успешным результатом никогда не перезаписывается.
- **Ни один checkpoint не становится основной моделью автоматически.** Выбор, проверка качества и активация должны быть ручными и отдельно подтверждёнными.

В CI `scripts/verify-neural-lab.py` действительно обучает на CPU две конфигурации с шириной 32 и 48 и проверяет сохранение обоих checkpoints. Используется только синтетический корпус. Результаты не доказывают полезность ответов.

Замеры времени сделаны на runner, не на пользовательской RTX 3050. Эти задания не измеряют RSS, CUDA VRAM и реальное потребление памяти при обучении на GPU; приёмка 4 ГБ VRAM и Windows desktop остаётся открытой. Ollama не используется.
