# Одна Yorika — один активный мозг

У Yorika один выбранный checkpoint собственной нейросети и единая долговременная память. Другие checkpoint из лаборатории — только неактивные исследовательские файлы, не независимые личности.

Для ручного выбора проверенного локального `.pt` внутри выделенного каталога можно вызвать `backend.active_brain.select_brain(model_directory, checkpoint_path)`. Создаётся `active-brain.json`, который не перезаписывается автоматически. `active_brain(model_directory)` читает единственный выбранный checkpoint с защитой от выхода за каталог. `scripts/local-model.py` использует его при заданной переменной `YORIKA_MODEL_DIRECTORY`.

Старый `YORIKA_NEURAL_CHECKPOINT` временно поддерживается для обратной совместимости. Модель по-прежнему экспериментальная, не гарантирует хорошие диалоги. Смена мозга вручную, измерение GPU и окончательная Windows GUI приёмка — следующие отдельные работы. Ollama не используется.
