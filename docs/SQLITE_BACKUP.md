# Проверяемый ручной снимок базы SQLite

Утилита `scripts/sqlite_backup.py` создаёт отдельный файл SQLite через SQLite Online Backup API, открывает снимок только для чтения, проверяет `PRAGMA integrity_check` и вычисляет SHA-256. Исходный файл не изменяется.

## Использование

```powershell
python scripts/sqlite_backup.py "$env:LOCALAPPDATA\Yorika\data\yorika.sqlite3" "$env:USERPROFILE\Documents\yorika-backup.sqlite3"
python -m unittest tests.test_sqlite_backup -v
```

Файл назначения должен отсутствовать. Утилита отказалась бы перезаписывать существующий файл или открытую исходную базу. При ошибке временный неполный снимок удаляется.

**Граница функции:** резервное копирование реализовано; автоматическое расписание, ротация, шифрование, системный restore и проверка на реальном Windows не реализованы. Для восстановления закройте Yorika, сохраните оригинал и сначала проверьте копию в отдельной тестовой папке. Никогда не заменяйте рабочую базу через этот CLI: он создаёт только снимки.

Локальная проверка в изолированной среде Linux: 3 unittest прошли (WAL, Unicode, integrity, запрет перезаписи). Windows end-to-end предстоит.
