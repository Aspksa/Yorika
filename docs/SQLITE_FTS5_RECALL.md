# Поиск воспоминаний SQLite через FTS5

`Store.search_records_fts(namespace, query, limit=20)` извлекает текстовые значения JSON-записей только выбранного пространства имён, индексирует их во временной базе SQLite FTS5 с `unicode61` и возвращает результаты, отсортированные по `bm25`. Каждая запись содержит `record_id`, `value`, `updated_at`, `rank`.

Поиск не включает JSON-ключи, не раскрывает записи из других пространств имён и не отправляет данные в сеть. Запрос преобразуется в набор буквальных терминов, объединённых AND, поэтому пользовательские операторы FTS5 не выполняются. Максимум 20 терминов, 100 символов на термин и 100 результатов.

**Ограничения:** индекс создаётся заново при каждом запросе и не масштабируется на большие объёмы; это лексический, а не семантический поиск. FTS5 зависит от сборки SQLite; без поддержки метод возвращает ошибку. Отдельной таблицы происхождения воспоминаний и интеграции поиска в ответы модели пока нет. Эти функции не означают завершения MEMORY-001 или четырёх этапов целиком.
