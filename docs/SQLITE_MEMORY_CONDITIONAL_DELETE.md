# Удаление воспоминания с проверкой актуальности

`Store.delete_record_if_unchanged(namespace, record_id, expected_value)` удаляет запись только если она существует и её JSON-содержимое совпадает с ожидаемым. Возвращает `False`, если запись уже изменена или отсутствует. В отличие от безусловного `delete_record()`, этот метод защищает от удаления новой версии воспоминания через устаревший интерфейс.

Метод выполняет проверку и условный SQL `DELETE` в одной транзакции, не удаляя записи других пространств имён.

**Ограничения:** сравнивается содержимое, а не уникальная ревизия: если значение изменили и вернули обратно (ABA), метод не обнаружит промежуточное изменение. Удаление не стирает старые резервные копии и WAL. UI памяти и полный Windows CI остаются в работе.
