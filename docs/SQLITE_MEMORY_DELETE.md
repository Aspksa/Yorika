# Удаление записи локальной памяти

Метод `Store.delete_record(namespace, record_id)` удаляет одну JSON-запись из таблицы `records` по точному совпадению пространства имён и идентификатора. Возвращает `True`, если запись была удалена, и `False`, если она отсутствовала. Пустые значения параметров отклоняются.

Удаление транзакционное и не затрагивает записи с таким же `record_id` в других пространствах имён. Это низкоуровневый API хранения, а не пользовательский экран управления памятью.

**Ограничение приватности:** удаление из активной SQLite-таблицы не означает мгновенного физического стирания содержимого из WAL, резервных копий, файлов синхронизации и прошлых экспортов. Будущий интерфейс должен объяснять эти ограничения и давать пользователю контролировать копии. `MEMORY-005` остаётся открытой до полноценной реализации просмотра, исправления, экспорта и удаления.
