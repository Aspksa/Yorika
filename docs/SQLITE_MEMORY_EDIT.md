# Безопасное исправление локального воспоминания

Метод `Store.update_record_if_unchanged(namespace, record_id, expected_value, new_value)` исправляет уже существующую JSON-запись только тогда, когда её сохранённое содержимое соответствует `expected_value`. Возвращает `True` при обновлении и `False`, если запись удалена или уже изменилась.

Выполняется транзакция SQLite с условным `UPDATE ... WHERE payload=?`, что предотвращает слепую перезапись устаревшим редактором. Пространство имён и идентификатор обязательны, оба значения должны быть объектами JSON. Метод не создаёт новые записи.

**Ограничения:** сравнение идёт по JSON-значению и фактической сохранённой строке внутри транзакции. API пока не подключён к экрану редактирования; не реализованы история правок, согласование конфликтов в интерфейсе, удаление резервных копий и комплексная приёмка Windows. `MEMORY-005` остаётся незавершённой.
