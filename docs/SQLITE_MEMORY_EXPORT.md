# Экспорт сохранённых воспоминаний Yorika

Метод `Store.export_records(namespace)` возвращает JSON-совместимый словарь с полями `format: "yorika-records-v1"`, `namespace` и `records`. Каждая запись содержит `record_id`, `value` и `updated_at`. Записи сортируются по идентификатору для повторяемости выгрузки.

Экспорт ограничен указанным пространством имён и не включает данные из других `namespace`. Пустое имя отклоняется. Экспорт читает активную SQLite-базу и не изменяет её.

**Безопасность:** экспорт содержит содержимое выбранной памяти в открытом виде. Не публикуйте его и не передавайте третьим лицам без проверки. Вызов создаёт объект в оперативной памяти; интерфейс скачивания файла, потоковый экспорт, шифрование, импорт и удаление старых копий ещё не реализованы. Для больших пространств имён возможен значительный расход RAM.

Это часть будущего управления приватностью, а не полное выполнение `MEMORY-005`. Проверка на Windows и сквозная приёмка ещё требуются.
