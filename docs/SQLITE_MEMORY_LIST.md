# Локальный список записей памяти Yorika

Метод `Store.list_records(namespace, limit=100)` позволяет получать уже сохранённые записи SQLite из одного пространства имён без обращения к внешним облакам.

Возвращает массив объектов `{"record_id": "...", "value": {...}, "updated_at": "..."}`, отсортированных по `updated_at DESC, record_id ASC`. Параметр `limit` обязан быть целым числом от 1 до 1000 (логические значения исключаются). Значение `namespace` обязательно, выборка выполняется через параметризованный SQL-запрос.

Это **не** семантический поиск, не FTS-индекс и не автоматическая память модели. Метод только извлекает уже сохранённые JSON-записи. Дальнейшие шаги: полнотекстовый поиск, ранжирование и интеграция в диалог. Полное тестирование на Windows и приёмка задач памяти остаются открытыми.
