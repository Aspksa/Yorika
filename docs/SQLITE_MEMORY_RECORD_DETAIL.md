# Чтение отдельной записи памяти Yorika

Метод `Store.get_record(namespace, record_id)` возвращает сведения об одной сохранённой записи в формате `{"record_id": "...", "value": {...}, "updated_at": "..."}` или `None`, если запись отсутствует. Запрос параметризован и ограничен заданным пространством имён.

В отличие от `Store.get()`, метод включает дату обновления, необходимую будущему экрану редактирования и истории изменения воспоминаний. Само чтение не изменяет данные.

**Важно:** `updated_at` — справочное время, а не уникальный идентификатор ревизии и не надёжный CAS-токен. Для защиты от параллельных изменений пока используйте `update_record_if_unchanged` или `delete_record_if_unchanged`. Полноценный UI, история ревизий и проверка на Windows ещё не завершены.
