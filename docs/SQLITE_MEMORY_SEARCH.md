# Локальный текстовый поиск по памяти Yorika

Метод `Store.search_records(namespace, query, limit=20)` ищет буквальное вхождение строки в **текстовых значениях** сохранённых JSON-записей `records` одного пространства имён, включая вложенные объекты и списки. Он использует Unicode `casefold()` для регистронезависимого поиска, включая кириллицу (например, `Ёрика` / `ёРИКА`).

Результаты возвращаются с полями `record_id`, `value`, `updated_at` по убыванию времени изменения. `limit` — целое число от 1 до 100. Пространство имён обязательно; пустой запрос отклоняется. Функция полностью локальная и не отправляет пользовательские данные в интернет.

**Ограничения:** это линейный перебор JSON-строк внутри namespace, а не полнотекстовый индекс FTS5, не семантический поиск и не ранжирование по релевантности. Имена JSON-ключей и числовые значения в поиск не включаются. Для большой памяти понадобится отдельный индекс и выбор полей, доступных для поиска. Полный Windows smoke-test ещё не подтверждён.
