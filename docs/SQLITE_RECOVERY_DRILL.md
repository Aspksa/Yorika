# Сквозная проверка восстановления памяти Yorika

`scripts/sqlite_recovery_drill.py` выполняет неразрушающий тест резервной копии: проверяет SHA-256, `integrity_check` и схему Yorika v1, восстанавливает копию в **новый файл внутри временной папки**, повторно проверяет контрольную сумму и количества записей `records` и `events`, после чего временная папка автоматически удаляется.

Запуск из корня проекта:

```powershell
python scripts/sqlite_recovery_drill.py "C:\\Users\\USERNAME\\Documents\\yorika-backup.sqlite3" --sha256 "SHA256_FROM_BACKUP_REPORT"
python -m unittest tests.test_sqlite_recovery_drill -v
```

Параметр `--sha256` обязателен: используйте значение, выданное при создании проверенной резервной копии. Код **не заменяет** `%LOCALAPPDATA%\\Yorika\\data\\yorika.sqlite3` и не меняет живую память. В отчёте выводятся только контрольная сумма, версия схемы и количества записей, без содержимого личной памяти.

**Предел проверки:** успешный drill доказывает возможность прочесть и восстановить конкретную копию во временный файл в среде запуска. Он не включает остановку работающей Yorika, переключение рабочей базы, восстановление DPAPI-ключей и полный Windows/NTFS smoke test. `DATA-003` и `DATA-006` остаются открытыми до приёмки.

Локальный smoke test нового сценария с эквивалентными вспомогательными SQLite-модулями: 2/2 на Linux. Полный тест репозитория `tests/test_sqlite_recovery_drill.py` в этой сессии не запускался.

## Достоверность отчёта и CI

Поле `temporary_copy_removed: true` формируется только после выхода из временного каталога и проверки отсутствия восстановленного файла. Ошибка удаления не должна выдаваться за успешный drill.

Наблюдение CI на 18 октября 2026: задания GitHub Actions `Chat memory safety` и `Windows PowerShell validation` завершались ошибкой, не начав ни одного шага (`steps=[]`), а журналы jobs недоступны. Это **не** результат выполнения Python-тестов. Для диагностики нужно проверить Actions в настройках репозитория, доступность hosted runners и лимиты биллинга; после восстановления запуска повторить обе матрицы и только затем принимать DATA-006 на Windows.
