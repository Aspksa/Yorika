# Обновление Yorika

Доступ: кнопка ☰ внизу слева → «Обновление».

Канал **Свежий** проверяет последний коммит main. Канал **Стабильный** проверяет последний опубликованный GitHub Release. Проверка по таймеру выполняется **только пока открыт сайт**. При обнаружении изменений отображается отметка в меню.

Приватный репозиторий требует GitHub personal access token с доступом на чтение Contents. Токен сохраняется в `.yorika/github-token.dpapi` с защитой DPAPI текущего пользователя Windows и не возвращается в браузер после сохранения. Токен доступен локальному приложению с правами того же пользователя; не считайте его защищённым от вредоносных программ под этой учётной записью.

По нажатию «Скачать и проверить» архив скачивается в системный каталог TEMP, проверяются состав и опасные пути внутри ZIP, затем вычисляется SHA-256. Проверенный пакет перемещается в `.yorika/staging/<sha>.zip`. Текущие файлы приложения при этом **не изменяются**.

**Важно:** этот этап реализует обнаружение и подготовку пакета. Автоматическая замена работающей версии и откат ещё НЕ включены: они требуют безопасной остановки процесса, резервного копирования, атомарного переключения и испытаний на Windows. До появления этих гарантий кнопки «Установить» нет. Не выдавать предварительную проверку структуры ZIP за криптографическую проверку происхождения пакета; hash считается для обнаружения последующих изменений файла, но не сверяется с подписанным манифестом GitHub.

Идентификатор установленного коммита пока неизвестен для скачанной вручную копии ZIP: при первой проверке может быть предложен существующий коммит как «доступный». Это ограничение будет устранено после введения версии сборки / installed manifest.

При переносе на другую учётную запись Windows токен DPAPI необходимо ввести заново. Конфигурация `.yorika/updates.json` переносима в пределах папки, но данные браузерной IndexedDB зависят от порта.

## Испытания
Необходимо проверить русские пути, работу с приватным токеном, сохранение и удаление, оба канала, поведение при отсутствии релизов, обновления в TEMP и запрет изменения рабочей версии. Эти сценарии ещё не пройдены на устройстве пользователя.
