# Профиль Йорики: 1024 реплики и 473 диалога

Исходный JSON из пользовательского вложения сохранён без правок по пути `backend/personas/yorika_soul_personality_1024_ru.json`. Он содержит 1024 реплики в 52 категориях и 473 сценария из `dialogue_extension`.

Модуль `backend/persona_profile.py` проверяет идентификатор и структуру профиля, загружает `runtime_prompt_capsule`. Скрипт `scripts/cloud-ru-model.py` добавляет профиль к системным инструкциям Cloud.ru во время ответов. Профиль не заменяет ограничения работы с непроверенными воспоминаниями; Cloud.ru по-прежнему используется вместо локальной LLM. При отсутствии JSON работает краткая резервная версия личности.

Полные реплики и сценарии сохранены в репозитории как библиотека примеров, но автоматический семантический выбор каждого сценария и гарантированная неповторяемость ответов пока не включены. Требуются отдельный селектор, тесты сохранения истории и проверка на Windows.

Данный JSON — художественный персонаж и примеры ответов, а не обученная нейросеть.
