# Yorika portable tests — двойной клик

После скачивания/распаковки **полного репозитория Yorika** откройте папку
`tools/portable-tests` и запустите **`START-TESTS.bat`**.

- Windows 10/11 x64. Нужен интернет **только при первом запуске** для загрузки
  официального Python 3.12.10 embedded ZIP с python.org.
- Установленный Python 3.14 не используется и системный PATH не меняется.
- Локальная portable-среда создаётся здесь, в `tools/portable-tests/runtime`
  (эта папка исключена из Git). ZIP тоже исключён из Git.
- Скрипт берёт код из текущей копии репозитория автоматически; вводить путь не нужно.
- Выполняются `scripts/run-acceptance.py`, SQLite tests и остальные тесты набора.
- Отчёт: `%LOCALAPPDATA%\\YorikaTestReports\\yorika-portable-acceptance.json`.
- Ненулевой код завершения означает сбой хотя бы одной проверки, отсутствие
  необходимых зависимостей или ошибку запуска. Ничего не отмечается как успешное без отчёта.

**Безопасность:** не нужны GitHub PAT, Cloud.ru ключи или runner токены. Не
запускайте код непроверенного репозитория. Первая загрузка идёт по HTTPS с
python.org, однако эта версия скрипта пока **не закрепляет SHA-256**
скачанного архива; в корпоративной среде убедитесь, что загрузка разрешена,
и отдельно проверьте подлинность дистрибутива. Флешка не нужна, но можно
переносить всю копию проекта вместе с runtime (без секретов).

**Ограничения:** официальный embedded Python не содержит pip. Если тесты
требуют внешних библиотек, они могут не пройти; журнал точно укажет ошибки.
Для GUI, DPAPI, Node.js и реального Cloud.ru требуются отдельные проверки.
Этот BAT **не исправляет и не запускает GitHub Actions runner автоматически**.
