Локальный сервер

Yorika работает только на этом компьютере. Порт выбирается заново при каждом запуске.

Yorika.bat /status
Показать адрес запущенной Yorika
Yorika.bat /log
Открыть журнал в Блокноте
Yorika.bat /rollback
Вернуться к прежней версии после обновления
03

Cloud.ru — ИИ

API-ключ шифруется Windows DPAPI для текущего пользователя. В браузере ключ не хранится и повторно не показывается. Отправка сообщений и выбранных воспоминаний в Cloud.ru может тарифицироваться.

Список подсказок не является каталогом всех доступных моделей. Можно вставить любой точный ID модели из Cloud.ru; доступ проверяется отдельной кнопкой и может тарифицироваться.

04

Рост личности Йорики

Дополнительные реплики хранятся локально в SQLite. При включённом накоплении после каждых 20 подходящих сообщений Йорика автоматически запрашивает у Cloud.ru новые варианты; это может тарифицироваться. Проверка личных данных и похожих фраз эвристическая и не гарантирует полной защиты.
