Языковая модель

Проверка…

Чат с аватаром отвечает через Cloud.ru Foundation Models. Запросы идут через локальный сервер Yorika: ключ шифруется Windows DPAPI для текущего пользователя, в браузере не хранится и повторно не показывается. Отправка сообщений и выбранных воспоминаний в Cloud.ru может тарифицироваться.

Выберите из загруженного списка ниже или введите ID вручную: подойдёт любой точный ID из Cloud.ru.

04

Память и предпочтения

Долговременная память Yorika хранится в SQLite на этом компьютере. Предпочтения сохраняются только по вашему явному действию, воспоминания можно исправить или удалить.

      05

      Рост личности Йорики

      Дополнительные реплики хранятся локально в SQLite. При включённом накоплении после каждых 20 подходящих сообщений Йорика автоматически запрашивает у Cloud.ru новые варианты; это может тарифицироваться. Проверка личных данных и похожих фраз эвристическая и не гарантирует полной защиты.
