# Единый запуск Yorika

В папке **ЦЕНТР_YORIKA** теперь нужен только **ЦЕНТР_YORIKA.bat**.

Запусти его двойным щелчком. Меню:
1. Проверка и установка недостающих инструментов: PowerShell 7, Node.js, Git, actionlint, uv, zizmor; системный Python только диагностируется.
2. Анализ GitHub Actions инструментами actionlint и zizmor.
3. Открытие внутреннего меню Python/SQLite и статусов (если политика PowerShell разрешает сценарии).
4. Проверка наличия инструментов.
0. Выход.

Удалены три отдельных BAT: `ПРОВЕРИТЬ_GITHUB_CI.bat`, `ПРОВЕРИТЬ_И_УСТАНОВИТЬ_ЗАВИСИМОСТИ.bat`, `УСТАНОВИТЬ_ПРОВЕРКИ_CI.bat`. Вспомогательные `.ps1` сохранены для проверок и существующего GitHub CI.

**Установка только после подтверждения пользователя** через winget / uv. После установки закрой и снова открой CMD, чтобы обновился PATH.

**Безопасность:** ранее Kaspersky заблокировал архив. Сначала выясни причину детекта, не отключай антивирус и не добавляй исключения. BAT не обходит Execution Policy, и при Restricted запуск PS1 не выполняется. Наличие команд не доказывает успешного выполнения тестов. GitHub-hosted CI и полная Windows-приёмка требуют отдельного запуска.
