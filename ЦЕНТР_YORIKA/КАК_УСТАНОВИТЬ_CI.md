# Проверка GitHub CI на Windows — actionlint и zizmor

В папке `ЦЕНТР_YORIKA` добавлены два BAT-файла, **работающие из CMD и не требующие PowerShell-скриптов**.

## Установка
1. **Сначала** выясните причину предупреждения Kaspersky о Yorika; не отключайте защиту и не создавайте исключения. Устанавливайте только из проверенной копии проекта.
2. Запустите `УСТАНОВИТЬ_ПРОВЕРКИ_CI.bat`. Он спрашивает разрешение перед установкой через Windows Package Manager (winget).
3. Используются пакеты `rhysd.actionlint` (проверка синтаксиса GitHub workflow) и `astral-sh.uv` (менеджер Python-инструментов). Затем через `uv tool install zizmor` устанавливается аудитор безопасности CI. **Испорченный системный Python 3.14 не требуется**: uv при необходимости подготовит совместимый Python.
4. После установки **закройте CMD и откройте снова** — новый PATH может не попасть в старое окно. Если установщик просит перезапустить командную строку, повторите запуск.
5. Откройте `ПРОВЕРИТЬ_GITHUB_CI.bat`. Он запускает `actionlint` и `zizmor` на `.github/workflows`.

Цветные метки: `[PASS]` — успешно; `[FAIL]` — ошибка анализатора или проблемы в CI; `[NOT RUN]` — программа недоступна и проверка **не выполнялась**. Результаты выводятся в окно CMD; скрипт не отправляет исходники и ключи сторонним сервисам самостоятельно. Пакетные менеджеры обращаются в свои официальные источники загрузки.

## Ручные команды в CMD

```cmd
winget --version
winget install --id rhysd.actionlint --exact
winget install --id astral-sh.uv --exact
uv tool install zizmor
actionlint -version
zizmor --version
actionlint
zizmor .github/workflows
```

## Ограничения

* Запуск из чата **не устанавливает ничего на ваш компьютер**. Только запуск BAT пользователем инициирует скачивание и установку.
* Установка зависит от доступности winget, сети и правил безопасности Windows. На управляемом устройстве нужно разрешение администратора.
* `actionlint` и `zizmor` делают **статический аудит GitHub Actions**, а не запускают Python, Node.js, GUI Yorika или настоящую интеграцию Cloud.ru. Результаты содержат диагностические сообщения анализаторов, не все они будут на русском.
* Обнаруженные проблемы требуют проверки разработчиком. Пропуск тестов никогда не означает успешную приёмку.
* Сигнатура Kaspersky `HEUR:Trojan.PowerShell.Agent.c` ранее была обнаружена в архиве. Ни один из BAT не ослабляет безопасность, не обходит Execution Policy и не исключает файлы из проверки.

## Единая проверка всего окружения Windows

Для проверки PowerShell 7, Node.js LTS, Git, actionlint, uv, zizmor и состояния системного Python используйте **`ПРОВЕРИТЬ_И_УСТАНОВИТЬ_ЗАВИСИМОСТИ.bat`**. Он работает из обычного CMD, не требует запуска `.ps1` и **спрашивает подтверждение перед установкой каждого отсутствующего инструмента** через winget или uv. Если winget отсутствует, покажет инструкцию вместо неподтверждённой загрузки. По окончании закройте CMD и откройте снова, чтобы обновился `PATH`; повторная проверка отличит оставшиеся ошибки от успешно установленных зависимостей.

**Не запускайте BAT из архива, заблокированного Kaspersky, пока не выяснена причина обнаружения.** Никакая установка не изменяет Execution Policy или антивирус. Установщик не исправляет автоматически повреждённый системный Python: для тестирования Yorika предусмотрен отдельный Python 3.12, который требует разрешённого запуска сценария и отдельной проверки безопасности. Проверка наличия программ ещё не означает, что тесты Yorika прошли.
